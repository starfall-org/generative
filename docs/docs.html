Getting started

Generative is an Android AI client. It connects to services you choose; it does not host AI models or include API credits.

01 / INSTALLInstall the app

Get the latest APK from GitHub Releases and install it on Android 8.0 or later.

02 / CONNECTAdd a provider

Choose an AI service, then enter its endpoint and credentials or use a supported sign-in flow.

03 / CHATChoose a model

Select an available model and send a message. You can add more services and tools whenever you need them.

Before you begin: Some providers require an API key, an account with API access enabled, or a paid plan. Charges from those services are separate from Generative.

Helpful terms

You only need a provider and a model to begin chatting. The other connections are optional.

Provider
The AI service you connect, such as OpenAI, Anthropic, or Google.
Model
The AI you choose for a conversation. Different models can do different things.
API key
A private code from your AI service that lets Generative connect to it. Never share it.
Endpoint
The service's server address. Copy it from the service's official setup instructions.
MCP tool
An optional connection that lets your assistant do more, such as searching or accessing another service.

Connect an AI provider

A provider is the service that receives your prompts and runs a model. Generative supports OpenAI-compatible APIs, OpenAI Responses, Anthropic, Google Gemini, Ollama, and selected account-based sign-in integrations.

Add from the provider directory

  1. Open the Provider library in your browser on Android.
  2. Find a provider and tap Add Provider where one-tap setup is available.
  3. Confirm the link opens Generative and review the prefilled provider details.
  4. Enter your own API key or complete the supported sign-in flow, then save.

Provider links prefill connection details only. They do not contain an API key. Some services require manual setup instead of a one-tap link.

Add manually

  1. Open the Providers area in the app and choose to add a provider.
  2. Enter a recognizable name and the exact API base URL from the provider's official documentation.
  3. Select the API type that the service supports, then choose the matching authentication method.
  4. Enter the API key or required credentials, save the provider, and select a model offered by that service.

Use the endpoint from the provider's own docs; don't assume every service uses the same URL. If the service is OpenAI-compatible, its docs should explicitly state the compatible API base URL.

Keep credentials private. Never share a provider link containing a key, and don't paste API keys into public issues or screenshots. Use HTTPS endpoints when available.

Chat and models

  • Choose a provider and model that match the task and your available access.
  • Start a conversation by entering a prompt in the chat composer and sending it.
  • Switch models when you want a different capability, speed, or price. Model availability depends on the connected service.
  • Use attachments or tools only when the selected model and provider support them.

Generative is a client, not a model host. The selected provider processes your messages and may apply its own retention, safety, and usage policies. Check the provider's terms for details.

Prompts and profiles

Use saved prompt instructions and profiles to reuse the setup that works for you. For example, you can keep a concise writing instruction, a research-oriented instruction, or task-specific preferences instead of retyping them in every conversation.

  • Keep instructions clear and focused on the behavior you want.
  • Choose the relevant profile for the current task.
  • Review saved instructions periodically and remove anything you no longer need.

Connect MCP tools

Model Context Protocol (MCP) servers can give an assistant access to additional tools, such as search or information from another service. You do not need to connect any tools to start chatting.

  1. Obtain the server URL and authentication details from the server operator.
  2. Open the MCP/tools settings in Generative and add the remote server.
  3. Configure authentication if the server requires it, then save and connect.
  4. Enable only the tools you trust and need for the current workflow.
Be careful with permissions. A connected tool may read data or perform actions in another service. Only connect servers you trust, and review their available tools before enabling them.

Voice, images, and video

Generative can use Android text-to-speech and configurable speech services. It also exposes supported image and video generation workflows when the selected provider and model implement the required API.

  • For speech, check the selected speech service configuration and Android's available text-to-speech voices.
  • For image or video generation, use a provider and model with the required capability; a normal chat model may not support it.
  • Some services need separate credentials or charge separately for media generation.

Exact options vary by app version, provider, model, and account plan.

Use remote machines over SSH

You can save SSH connections and open an interactive terminal from your Android device. This is useful for working with a remote development environment or server without switching devices.

  1. Open the remote machines area and add a connection using the host, port, username, and supported authentication method supplied by your administrator or host.
  2. For key-based authentication, select or import the appropriate private key using the app's supported identity controls.
  3. Connect to the machine and open its terminal.
  4. Disconnect when finished, and remove saved connections you no longer use.

Only connect to machines you own or are authorized to access. Keep private keys and access tokens secure.

Privacy and security

  • Your providers receive the prompts you send. Their own privacy policies determine how submitted data is processed.
  • Credentials are sensitive. Don't publish API keys, passwords, private keys, or OAuth links.
  • Use trusted MCP servers. Tools may access external data or take actions with the permissions you grant.
  • Review your endpoint. Prefer HTTPS and verify that the domain belongs to the intended provider.
  • Usage may cost money. Check each service's pricing and quotas to avoid unexpected charges.

Troubleshooting

The provider fails to connect

Check the base URL, API type, authentication method, and key. Confirm that your account has API access and that the provider's service is available. Use the exact endpoint documented by the service.

The model I want isn't listed

Model catalogs differ by provider and plan. Check the provider's official model list and verify that the selected endpoint supports the model ID. Some services require you to enter or select a model manually.

The Add Provider link doesn't open the app

Open the provider directory on the Android device where Generative is installed. If your browser asks which app should handle the link, select Generative. You can also add the provider manually from within the app.

A tool or media action isn't available

Check whether the selected model and provider support the capability, and whether the required MCP server, speech service, or media credentials are configured.

Where can I report a problem?

Include the app version, Android version, the steps that reproduce the issue, and a redacted error message in the GitHub issue tracker. Remove API keys, tokens, private URLs, and other secrets before posting.

Need another starting point? Browse the provider directory or get the latest version from GitHub Releases.
